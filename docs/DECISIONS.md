# Decisions log — NUBU

## 2026-11-24 — สไตล์ตัวละคร: 2.5D ใน Rive (ไม่ทำ 3D เต็มตัว)
**ตัดสินใจ:** Nubu เป็น 2D rig ใน Rive แต่คงลุคนุ่มนิ่มแบบ plush 3D ด้วยเลเยอร์ภาพ + shading soft-clay
**เหตุผล:**
- ปริมาณคลิป 5–7/สัปดาห์ → เป้า 2–3/วัน, ข่าวต้องทำสด — render 3D ขนฟูช้าเกินไป
- Rig ตัวเดียว หน้าตาคงที่ทุกคลิป, ลิปซิงก์ไทยง่ายด้วยการสลับรูปปาก
- ภาพส่วนใหญ่เป็นภาพข่าว/ฟุตเทจที่มีสิทธิ์ Nubu เป็นตัวเล่ามุมจอ + ท่าทางตอบสนอง
**3D ใช้เฉพาะ:** thumbnail / intro bumper 3–5 วินาที (ไม่ rig)
**เงื่อนไขตรวจซ้ำ:** ทดลองคลิป 60 วินาที 1 คลิป ถ้าใช้เวลา > 1–1.5 ชม./คลิป ต้องลดความซับซ้อน rig

## 2026-11-24 — จุดต่างของ Nubu = เปลี่ยนชุด + ธีมสีตามวงที่เล่าข่าว (แก้จากร่างแรก)
**ตัดสินใจ:** ไม่ใช้ "สีหนวดเปลี่ยนตามอารมณ์/กลางวันกลางคืน" ให้ Nubu เปลี่ยนชุดและธีมสีตามวงที่กำลังเล่า
**ผลต่อดีไซน์:**
- ตัวฐานต้อง **เปลือยเรียบ** (ไม่มีชุด/เครื่องประดับ) แล้วชุดเป็นเลเยอร์สลับได้ 3 ช่อง: เสื้อ/แจ็คเก็ต · ของคอ/หัว · สีหูฟัง
- ธีมสีของวง = สีชุด + สีกราฟิก/lower-third/พื้นหลังของคลิปนั้น (ผูกสีผ่าน data binding ใน Rive)
- **ลายผีเสื้อลดเหลือจุดเดียว** (หนวดบนหัว) ถอดจากหูฟัง/ผ้าพันคอ/ที่อื่นออก
**ข้อควรระวังสิทธิ์:** ชุดอิงจาก "โทนสี/สไตล์คอนเซ็ปต์" ของวง ห้ามลอกโลโก้ อัลบั้มอาร์ต หรือแท่งไฟของจริง (กฎช่อง: ใช้เฉพาะของที่มีสิทธิ์)

## Pipeline ต่อคลิป (ร่าง)
สคริปต์ไทย → เสียง (ElevenLabs) → Rive ขยับปาก/ท่าทาง → ประกอบกับภาพข่าวด้วย HyperFrames/Remotion → ซับ → export 16:9 + ทีเซอร์ 9:16
