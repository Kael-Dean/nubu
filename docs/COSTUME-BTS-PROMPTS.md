## กติกาชุดประจำวง (ใช้กับทุกวง)
- ชุด = **ของที่ใส่เพิ่มบนตัวเดิม** ไม่เปลี่ยนตัว หน้า แขน หนวด ตำแหน่ง → ดึงเป็นเลเยอร์แยกได้ แล้วเปิด/ปิดใน Rive ตามวง
- แต่ละวงใช้ 3 ชิ้นแบบเดียวกัน: **หมวกบีนนี่ไหมพรม · ปลอกหูฟัง · ผ้าพันคอ** (เปลี่ยนสี/ลวดลายตามวง)
- ไม่ใส่เสื้อมีแขน (ต้องทำแขนเสื้อแยกทุกท่ามือ 2 มุม) · ผ้าพันคออยู่ใต้แขนในลำดับเลเยอร์ จึงไม่บังท่ามือ
- **ไม่ใส่โลโก้วง / โลโก้ ARMY / ชื่อวง / ตัวอักษรใดๆ** — โลโก้ BTS และ ARMY เป็นเครื่องหมายการค้าของ BIGHIT MUSIC / HYBE ช่องเราหารายได้ ใส่แล้วเสี่ยงโดนร้องเรียน และดูเหมือนเป็นสินค้าทางการ
  → สื่อถึงวงด้วย **สีม่วง + หัวใจ + ดาว 7 ดวง** (7 = จำนวนสมาชิก)
- สีชุดเป็นม่วงเข้ม-กลาง ไม่ใช่ลาเวนเดอร์อ่อน → ไม่กลืนกับหนวดผีเสื้อและตัวสีครีม และดึงเลเยอร์ด้วยการแยกสีได้ง่าย
