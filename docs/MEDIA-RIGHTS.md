# คู่มือสิทธิ์ภาพ/ฟุตเทจ สำหรับช่อง Nubu (ร่าง 2026-11-24)

> ไม่ใช่คำแนะนำทางกฎหมาย — เป็นแนวปฏิบัติเพื่อลดความเสี่ยง ถ้าจะใช้งานใดเป็นประจำ หรือได้รับ claim/strike ควรปรึกษาผู้เชี่ยวชาญลิขสิทธิ์
> กฎช่อง (CHANNEL-BRIEF ข้อ 8): **ใช้เฉพาะรูปและฟุตเทจที่มีสิทธิ์**

## หลักคิด 3 ข้อ
1. **ค่าเริ่มต้น = ห้ามใช้** เกือบทุกอย่างของเคป็อปมีเจ้าของ: ค่าย (HYBE, SM, JYP, YG ฯลฯ), สถานี (KBS, MBC, SBS, Mnet), ช่างภาพ/สำนักข่าว (Dispatch, Yonhap, Newsen ฯลฯ), แม้แต่แฟนแคมก็มีเพลงและการแสดงของค่ายอยู่ข้างใน
2. **YouTube ตัดสินด้วย Content ID อัตโนมัติ ไม่ได้ดูกฎหมายไทย** — เพลงไม่กี่วินาทีหรือภาพ MV ก็โดน claim ได้ (เสียรายได้/บล็อกบางประเทศ) และถ้าเจ้าของยื่นถอด = copyright strike (ครบ 3 ครั้ง ช่องถูกปิด)
3. **ข้อยกเว้นในกฎหมายไทยแคบและไม่แน่นอน** — พ.ร.บ.ลิขสิทธิ์ 2537 มาตรา 32–43 มีข้อยกเว้น เช่น การติชม/วิจารณ์ และการเสนอรายงานข่าวโดยรับรู้ความเป็นเจ้าของ แต่ต้อง "ไม่ขัดต่อการแสวงหาประโยชน์ตามปกติ และไม่กระทบสิทธิเจ้าของเกินสมควร" — การเอา MV/ฟุตเทจคอนเสิร์ตมาใส่คลิปที่สร้างรายได้มักไม่ผ่านข้อนี้ และไม่ช่วยอะไรตอนโดน Content ID

## ไฟจราจร
### 🔴 แดง — ไม่ใช้
- MV, ทีเซอร์, ฟุตเทจรายการเพลง/วาไรตี้, ไลฟ์ Weverse/Bubble, คลิปคอนเสิร์ต, แฟนแคม
- **เพลงทุกเพลง** (แม้เป็น BGM สั้นๆ)
- รูปจาก IG/X ทางการของศิลปิน/ค่าย, รูปจากสำนักข่าว (Dispatch, Naver), รูปจาก Pinterest/Google รูปภาพ
- ภาพหน้าจอฉากซีรีส์/โปสเตอร์ซีรีส์ (เว้นแต่มีสิทธิ์ editorial)

### 🟡 เหลือง — ใช้ได้เมื่อมีหลักฐานสิทธิ์ต่อชิ้น
- **ภาพ editorial ที่ซื้อลิขสิทธิ์** (Getty Images, Shutterstock Editorial ฯลฯ) — อ่านเงื่อนไขว่าครอบคลุม "วิดีโอออนไลน์ที่สร้างรายได้" ไหม เก็บใบเสร็จ/ใบอนุญาต
- **Creative Commons / KOGL** (เช่นบน Wikimedia Commons, Korea.net) — **เช็กทีละภาพ**: ต้องเป็นแบบที่อนุญาตเชิงพาณิชย์ (CC BY, CC BY-SA, KOGL Type 1 — แต่ KOGL ยังตีความต่างกันเรื่องเชิงพาณิชย์) ใส่เครดิตตามที่กำหนด บางภาพของ Korea.net มีเงื่อนไขพิเศษ ("เฉพาะสื่อข่าว", "ห้ามสื่อว่ารัฐบาลรับรอง")
- **ภาพข่าว/press kit ที่ค่ายแจกสื่อ** — มักให้เฉพาะสื่อมวลชน ถ้าจะใช้ต้องขออนุญาตหรือมีหลักฐานว่าเปิดให้ใช้
- **ภาพหน้าจอประกาศ/โพสต์ทางการที่เป็นข้อความ** (เช่น ประกาศผู้จัดคอน) — ใช้เป็นหลักฐานอ้างอิงสั้นๆ พร้อมบอกแหล่ง ดีกว่าคือ **พิมพ์ข้อความใหม่เป็นการ์ดของเราเอง** แล้วเขียนแหล่งที่มา

### 🟢 เขียว — ใช้ได้เลย
- **Nubu ทั้งหมด** (ของเราเอง) + ภาพ/การ์ดข้อความ/แผนที่/ไอคอนที่ทำเอง
- **ภาพ/วิดีโอที่ถ่ายเอง** ในที่สาธารณะ (เช่น หน้าสนาม ทางเดินจากสถานี) — ห้ามถ่ายการแสดงในคอนเสิร์ตมาใช้
- **คลังภาพ/เพลงฟรีที่อนุญาตเชิงพาณิชย์** (เช่น YouTube Audio Library, ภาพสต็อกฟรีที่ระบุชัด) — เก็บลิงก์ใบอนุญาต
- **AI สร้างเอง** สำหรับภาพประกอบทั่วไป (ห้ามสร้างหน้าศิลปินจริง/โลโก้ค่าย/ปกอัลบั้มเลียนแบบ)

## สูตรภาพของช่อง (ที่เข้ากับข้อจำกัด)
Nubu เล่า + การ์ดข้อความ/พาดหัวที่ทำเอง + แผนที่/อินโฟกราฟิกที่ทำเอง + ภาพถ่ายเองหรือภาพมีใบอนุญาต (ถ้ามี) + บอกแหล่งข่าวบนจอทุกครั้ง
→ แข่งด้วย "สรุปหลายแหล่งให้ฟังแบบเพื่อน" ไม่ใช่ด้วยฟุตเทจ

## เช็กก่อนลงทุกคลิป
1. ทุกภาพ/เสียงที่ไม่ใช่ของเรา มีแถวใน `assets/licensed-media/LOG.csv` (แหล่ง, ใบอนุญาต, เครดิตที่ต้องใส่)
2. ใส่เครดิตตามใบอนุญาตบนจอหรือในคำอธิบายคลิป
3. อัปโหลดเป็น **ส่วนตัว (Private) ก่อน** แล้วดูผลตรวจลิขสิทธิ์ใน YouTube Studio (Checks) ให้ผ่านก่อนกดสาธารณะ
4. ถ้าโดน claim: อย่ากดโต้แย้งถ้าไม่มีหลักฐานสิทธิ์ — ตัดส่วนนั้นออกแทน

## วิดีโอสั้น / ภาพถ่ายไอดอล ใช้ได้แค่ไหน (เพิ่ม 2026-11-24)
**ไม่มีกฎ "ไม่เกิน X วินาทีแล้วปลอดภัย"** — เป็นความเชื่อผิด ระบบเคลมจับได้แม้ไม่กี่วินาที และเจ้าของยื่นถอดได้ทุกความยาว
ข้อพิพาทบน YouTube พิจารณาตามหลัก fair use ของสหรัฐฯ (YouTube เป็นบริษัทสหรัฐฯ) ซึ่งดูจาก: ใช้เพื่อวิจารณ์/รายงานข่าวไหม · เปลี่ยนรูปแบบไปมากแค่ไหน · ใช้มากแค่ไหน · ทดแทนของต้นฉบับไหม — ไม่มีอะไรรับประกัน

### บันไดความเสี่ยง (ต่ำ → สูง)
1. **ต่ำมาก:** ของทำเอง · ภาพ editorial ที่ซื้อใบอนุญาต · ภาพ CC ที่อนุญาตเชิงพาณิชย์ · **YouTube Shorts "Remix"** ตัดคลิปจากวิดีโอที่เปิดให้ remix บน YouTube เอง (ระบบใส่เครดิตให้ — ใช้ได้เฉพาะ Shorts, เช็กกฎปัจจุบันในหน้าช่วยเหลือ YouTube)
2. **กลาง:** ภาพนิ่ง (screenshot) จาก MV/ทีเซอร์ทางการ แสดงสั้นๆ ในกรอบเล็กข้าง Nubu ที่กำลังอธิบาย + เครดิต + ไม่มีเสียงต้นฉบับ — อาจโดนเคลม/ถอดได้ แต่โอกาสต่ำกว่าวิดีโอ
3. **สูง:** คลิปวิดีโอสั้นจาก MV/รายการ **แบบไม่มีเสียง** ในกรอบเล็กพร้อมคำอธิบาย
4. **สูงมาก (ห้าม):** คลิปที่มีเสียงเพลง/เสียงต้นฉบับ · แฟนแคม · คลิปเต็ม/ช่วงยาว · ภาพเต็มจอโดยไม่มีคำอธิบาย · ภาพที่ใช้ทำปก (thumbnail)

### ระวังเพิ่ม
- **เสียงเพลงคือตัวจุดชนวนหลักของ Content ID** — ตัดเสียงต้นฉบับทิ้งเสมอ
- **ภาพปกคลิป (thumbnail)** ห้ามใช้ภาพไอดอลที่ไม่มีสิทธิ์ (โดนแจ้งง่ายที่สุด และดูเป็นการค้า)
- **ห้ามใช้ AI สร้างหน้าไอดอลจริง** — เสี่ยงสิทธิในภาพบุคคล/ชื่อเสียง และขัดกฎช่องเรื่องความจริงใจ
- เคลม Content ID ส่วนใหญ่ = รายได้คลิปไปเป็นของเจ้าของ (ไม่ใช่ strike) แต่บางเจ้าของตั้งให้บล็อกคลิป · การยื่นถอดด้วยมือ = strike
- ทางเลี่ยงที่ดีมาก: ชี้ไปดูของจริง — "ไปดู MV ได้ที่ช่องทางการ ลิงก์ในคำอธิบาย" + การ์ดลิงก์บนจอ → ได้ใจค่ายและแฟนด้วย

### ✅ นโยบายช่อง — ผู้ใช้เลือก **B สมดุล** (2026-11-24)
- ใช้ได้: ระดับ 1 ทั้งหมด (ทำเอง, editorial ที่ซื้อ, CC เชิงพาณิชย์, Shorts Remix)
- ใช้ได้แบบจำกัด: ภาพนิ่ง (screenshot) จาก MV/ทีเซอร์/ประกาศ **ทางการ** เท่านั้น
  - ไม่เกิน **3 ภาพต่อคลิป**
  - แสดงภาพละไม่เกิน **3 วินาที**
  - อยู่ใน **กรอบเล็ก** ข้าง Nubu ที่กำลังอธิบาย (ไม่เต็มจอ)
  - มี **เครดิตบนจอ** (ชื่อค่าย/ช่องทางการ)
  - **ไม่ใช้บนปกคลิป** และไม่ใช้ใน teaser TikTok/IG ที่ไม่มีคำอธิบาย
  - จดลง `assets/licensed-media/LOG.csv` (license = "official still, policy B")
- ห้าม: ระดับ 3–4 (คลิปวิดีโอทุกแบบ, เสียงต้นฉบับ, แฟนแคม, ภาพเต็มจอ, AI หน้าไอดอล)
- ถ้าภาพนิ่งชิ้นไหนโดนเคลม/ถอด: ตัดออก ไม่โต้แย้ง และจดไว้ว่าเจ้าของรายนั้นเข้มงวด
